# Original generated game asset and memory cost

`src/assets/phoenix-city.webp` is original built-in image generation for this project, created November 10, 2026. Prompt direction: wide side-on ink/gouache 1950s retro-futurist city, brick tenements, water tanks, aerials, ducts, amber windows, charcoal/olive/blue; no characters, UI, readable signage or interaction targets; dark lower edge for editable procedural overlap. Inspected and compressed to 1536×512, 44,774 bytes. No third-party game/film frame was used. No promise of exclusivity or third-party license is made for generated output.

The exact game WebP is in the recovered review archive. The original full PNG was in the unavailable local workspace and could not be recovered for that archive. Existing procedural skyline remains a fallback. City layer is distant, non-interactive, urban-only and never defines hit areas or walkability. Decoded RGBA is about 3 MiB before copies; added working figure sheet about 1.16 MiB. Shared sets follow existing room-family cleanup. No runtime art service or new package.

All new facade, pipe, panel, broadcast, furniture, book and vegetation details are original code painting in `src/art/phoenix.ts` and `kits.ts`. Audio remains original synthesis. Existing engine/font license notices are preserved. No complete novel, commercial audio pack or protected film screenshot is included.
