# Test this version first — quick instructions

## Fastest Windows test (no npm install or build)

1. Extract the complete ZIP first. Do not run from inside the ZIP.
2. Double-click `START_GAME_WINDOWS.cmd` in the extracted top folder. Requires Node.js (Node 24 recommended). If Node is missing, install it, then reopen the launcher.
3. Open `http://localhost:4173/` in Chrome. Keep the command window open. Opening the game's HTML directly is unsupported.
4. For iPhone: use the printed `Phone on same trusted Wi-Fi` URL in Safari. Both devices must share Wi-Fi. If Windows asks, permit Node on the private network only. If the phone cannot connect, check firewall/network isolation; this is separate from game input. No phone installation or public deployment is required.
5. Stop with Ctrl+C. If port 4173 is busy, stop the previous review server first.

The launcher serves only the supplied built game. It does not install packages, edit saves, push, merge or publish. A local HTTP address has separate browser saves from the live website. Do not expect the live-site save on this address. Clearing site data deletes that address's saves.

## Five-minute smoke test

- New Game: tap immediately; walk right, hold E or ACT at the piles, release and retry. The first cinematic takes time; do not confuse a scripted wait with a dead control.
- Tap dialogue choices, J/journal, pause and resume. Press M or use Settings to hear/mute sound. Use low volume first.
- Pause a hazard, wait, return: hazard phase should stay put. Switch apps/lock the phone; return with the explicit resume button.
- Rotate phone both ways. Test movement plus ACT/DIVE together and release fingers outside controls. Targets should match their visible positions.
- Quit and Continue: resume the last safe checkpoint. Test Presentation Mode's five chapter starts; normal saved progress must survive. Demo starts prefill earlier challenge counts; they are not proof of a complete playthrough.
- For the classroom route, read `05_SCHOOL/DEMO_ROUTE.md` and rehearse with `PRESENTATION_SCRIPT.md`. For a full game, finish all 15 challenges and choose an ending.

If taps fail, add `?diagnostics` to the same URL, record the displayed scene, input counts, scale/errors and the last action. The panel stays local. The original physical-iPhone failure is not conclusively closed by Linux WebKit tests.
