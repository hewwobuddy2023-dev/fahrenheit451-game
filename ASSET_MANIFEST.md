## Acceptable sources

Original assets created specifically for the project; public-domain or clearly licensed assets with attribution when required; source documentation from official sites. Review each asset's license. Do not assume an image generated by a general web search is free to use. Do not copy copyrighted game screenshots into the distributed build.

The source novel is **private literary reference, not a shipped asset**.
