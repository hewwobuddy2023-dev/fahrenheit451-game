## Timing

Target 10–15 minutes means some objectives last 20–45 seconds; this is a severe compression risk. Prioritize meaningful interaction over artificial loading/walking. A full playthrough must be timed and documented. Never pretend each challenge is a full mission. If teacher requires 15 substantial independent challenges, adjust expected runtime or ask for clarification.

For each: ID, short title, in-world action, source section (`Part 1`, `Part 2`, `Part 3`), plot connection, status pending/completed, state flag, retry path. All flags must remain consistent after loading checkpoint and resetting new game.
